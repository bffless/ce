## Why

The Anthropic model list was a static array in `project-ai-settings.service.ts`. Every new model
(e.g. a `claude-opus-4-x` bump) required a code change + redeploy to show up. Anthropic exposes a
public `GET /v1/models`, so we pull the list live using the workspace's own key.

## The fetch: cache + tier classify + fallback

`/v1/models` returns `id`/`display_name` only — no tier or description — so we classify by family
locally and keep a tiny description map.

<Diff file="apps/backend/src/projects/project-ai-settings.service.ts" summary="fetchAnthropicModels — per-key cache (1h), fallback to static catalog on any failure"
  lines={[
    "+ const fallback = AI_PROVIDER_METADATA.anthropic.models;",
    "+ const cacheKey = crypto.createHash('sha256').update(apiKey).digest('hex');",
    "+ const cached = this.modelsCache.get(cacheKey);",
    "+ if (cached && cached.expires > Date.now()) return cached.models;",
    "+ const response = await fetch('https://api.anthropic.com/v1/models?limit=100', {",
    "+   headers: { 'x-api-key': apiKey, 'anthropic-version': '2023-06-01' } });",
    "+ if (!response.ok) return fallback;            // never empty the UI",
    "+ const models = data.data.map(m => this.toAnthropicModelInfo(m.id, m.display_name));",
    "+ this.modelsCache.set(cacheKey, { models, expires: Date.now() + 60*60*1000 });",
  ]} />
